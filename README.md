# Plantilla · Administrador de instructores y formación
 
Repositorio plantilla para los proyectos de grupo de la ficha 3229426
(Tecnólogo en Análisis y Desarrollo de Software).
 
## Cómo usar esta plantilla
1. El líder del proyecto crea su repositorio con el botón
   "Use this template" (ver módulo 7 del taller).
2. Ajusta docs/CODEOWNERS reemplazando pNN por el código real del proyecto.
3. Sigue el flujo feature -> develop -> main descrito en el módulo 8.
 
## Documentos de apoyo
- docs/definition-of-done.md : cuándo una historia está "Hecho"
- docs/rubrica-evaluacion.md : listas de chequeo y rúbrica del sprint
- docs/guia-aprendizaje-sprint1.md : guía de aprendizaje del primer sprint
